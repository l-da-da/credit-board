# 额度看板

在 DSH 侧边栏底部加一个「额度」入口，点开是一个浮层看板，汇总四家客户端的签到状态和余额，并能一键触发签到。

## 看板里有什么

| 应用 | 余额 | 签到状态 |
| --- | --- | --- |
| WorkBuddy | 点头像读「积分余额」 | 读客户端日志：是否已领、连签天数、今日领取额 |
| 豆包 | 总额度（「用豆包工作」页面的累计获得额度） | 读自动签到的运行结果，按账号列出 |
| CodeArts | 「积分用量」面板的积分余额 | 活动福利里的每日签到状态 |
| AutoClaw | 总积分 | 不参与签到 |

登录账号会与 `config.json` 的 `expectedAccounts` 比对，不一致时该行标红提示。

## 按钮

- **刷新余额**：在后台最小化启动各客户端，读取一次余额后自动关闭（约 30–60 秒）。
- **立即签到**：执行 `auto-checkin\run-checkin.ps1`，等同于计划任务的那次运行。
- **签到后保留客户端**：勾选后签到完不关闭客户端（豆包会带调试端口常驻，下次直接连上）；取消勾选则跑完就关。

## 依赖

面板通过本机 `http://127.0.0.1:47122` 读取数据，这个服务由计划任务 `DSH-CreditBoard` 在登录时启动；它只监听回环地址，不对外网开放。

数据来源：

- `auto-checkin\logs\last-result.json`（最近一次签到结果）
- `auto-checkin\logs\balance.json`（余额采集快照）
- `~/.workbuddy/logs/main.log`（WorkBuddy 今日签到状态）

## 限制

- WorkBuddy 的积分余额需要点头像面板才能读到，采集时会做这个动作（窗口最小化）。
- 豆包展示的是「用豆包工作」页面上的总额度（累计获得），剩余额度要去「设置 → 订阅与额度管理」看。
- 刷新余额会短暂启动客户端（最小化、不抢焦点），跑完自动关闭；你自己开着的应用不会被关。
- 面板「刷新余额 / 立即签到」只写 flag，由每分钟轮询的计划任务消费；确认 DSH-CheckinNow / DSH-CreditCollect 在跑。
